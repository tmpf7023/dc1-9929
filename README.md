## 限制与不适合谁

DC1 这两款套餐有三个绕不开的限制，下单前想清楚：

- **不支持机房迁移**。IP 和机房绑定，线路或 IP 出问题没有“换个机房”的退路；IP 被封后换 IP 需要付费，有攻略整理的价目是 $8/次。
